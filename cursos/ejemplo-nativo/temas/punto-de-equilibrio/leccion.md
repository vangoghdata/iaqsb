# El punto de equilibrio

El **punto de equilibrio** es la cantidad que hay que vender para que los ingresos cubran exactamente los costos: ni se gana ni se pierde. Responde preguntas como «¿cuántas mesas al mes tiene que vender el taller para no perder?» o «¿vale la pena una máquina nueva que sube los costos fijos pero baja el costo por unidad?».

## Las piezas

- **Costos fijos (CF):** no cambian con la cantidad producida en el corto plazo: arriendo, salarios de administración, depreciación.
- **Precio de venta (p):** lo que paga el cliente por unidad.
- **Costo variable unitario (cv):** lo que cuesta cada unidad adicional: materiales, mano de obra directa, empaque.
- **Margen de contribución (p − cv):** lo que deja cada unidad para pagar los costos fijos y, después, para la utilidad.

## Las fórmulas

- Punto de equilibrio en unidades: **Q* = CF / (p − cv)**
- En dinero: **Q* · p**
- Utilidad al vender Q unidades: **U(Q) = (p − cv) · Q − CF**

Si el precio no supera el costo variable (p ≤ cv), no hay punto de equilibrio: cada unidad vendida aumenta la pérdida.

## Cómo leer el resultado

Si la empresa vende más que Q*, gana; si vende menos, pierde. El **margen de seguridad** compara las ventas esperadas (o la capacidad) con Q*: cuanto más lejos de Q*, más resiste la empresa una caída de las ventas.

El análisis supone precio y costo variable constantes y que todo lo que se produce se vende. Es una herramienta de primera aproximación (Render et al., 2012).
